# 🎟️ Билетный Портал — Онлайн-платформа бронирования билетов (Костанай)

Премиальный веб-сервис для бронирования и покупки электронных билетов на культурно-зрелищные мероприятия города Костанай (Филармония, Драмтеатр им. Горького, Ледовая арена «Көктем»).

Проект разработан в рамках практических работ по предмету «Разработка программного обеспечения» (преподаватель: Тулегенов).

---

## 🛠 Технологический стек

- **Backend**: Laravel 11 (PHP 8.2+), Eloquent ORM, REST API Controllers.
- **Frontend**: Blade-компоненты (`@props`, `$slot`), HTML5 / CSS3 (Премиальная тёмная тема `#0A0A0B` / `#C6A368`), JavaScript (Fetch API).
- **База данных**: SQLite / PostgreSQL (Миграции, Сидеры, Транзакции).
- **Безопасность и Валидация**: Цифровая подпись QR-кодов по алгоритму HMAC-SHA256, защита от оверселлинга через пессимистические блокировки БД (`lockForUpdate`).
- **Интеграции**: `DomPDF` (генерация печатных билетов), `html5-qrcode` / `QRCode.js` (генерация и сканирование QR с веб-камеры).

## ✨ Реализованный функционал

### 1. 🎭 Афиша и фильтрация (`/events`)
- Каталог событий с фильтрацией по категориям (*Концерт, Театр, StandUp, Классика, Семья*) и поиском по названиям/площадкам.
- Бейджи статусов доступности билетов (`Доступен`, `Билеты заканчиваются`, `Завершено`).

### 2. 🪑 Интерактивная схема зала и бронирование (`/events/{id}`)
- Графическая схема размещения кресел с разбивкой по рядам и ценовым зонам (*VIP, Партер, Балкон*).
- Интерактивный выбор до 6 мест за один транзакционный заказ.
- Атомарная защита от двойных покупок (`DB::transaction` + `lockForUpdate`).

### 3. 🎫 Личный кабинет заказов и PDF-билеты (`/orders`)
- История покупок с детальной информацией о выбранных рядах и местах.
- Выгрузка и скачивание официального PDF-билета с уникальным QR-кодом для прохода.

### 4. 📷 Модуль контроля на входе (`/scan`)
- Считывание QR-кода билета через реальную физическую веб-камеру контролёра (`html5-qrcode`) или ручной ввод кода.
- Проверка валидности HMAC-подписи и мгновенное погашение билета с защитой от повторного прохода.

### 5. 📊 Аналитический дашборд (`/analytics`)
- Мониторинг суммарной выручки и количества проданных мест в реальном времени.
- Модуль ручного возврата средств с мгновенным освобождением мест в схеме зала.

### 6. ⚙️ Админ-панель (`/admin`)
- Форма быстрого создания новых мероприятий с привязкой к залам и настройкой цен.
- Просмотр структуры и вместимости площадок.

## 🧩 Архитектура Blade-компонентов (по методичке)

Все повторяющиеся элементы интерфейса вынесены в анонимные Blade-компоненты:
- `<x-app-layout>` — Главный каркас страницы с навигацией и стилями.
- `<x-event-card>` — Карточка мероприятия в афише.
- `<x-order-card>` — Карточка истории заказов.
- `<x-panel>` — Универсальный контейнер со слотом `{{ $slot }}`.
- `<x-alert>` — Всплывающие уведомления (*success, warning, error*).
- `<x-badge>` — Бейджи статусов заказов и доступности мест.

## 🗄 Структура базы данных

1. `halls` — Площадки и конфигурация залов (ряды, места, проходы).
2. `events` — Мероприятия, расписание и ценовые матрицы.
3. `seats` — Посадочные места с привязкой к ценовым зонам.
4. `orders` — Заказы пользователей, статусы оплаты и сроки брони.
5. `tickets` — Выпущенные билеты с уникальными кодами и статусом погашения (`is_used`).
